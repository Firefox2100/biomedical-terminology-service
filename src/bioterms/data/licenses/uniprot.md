# Licence of UniProtKB data

This project uses data from the UniProt Knowledgebase (UniProtKB), provided by the UniProt
Consortium. This project is not affiliated with or endorsed by the UniProt Consortium.

BioTerms extracts a subset of fields from the UniProtKB release and represents them in a
different format. If discrepancies are found, refer to the original UniProtKB release.
